> **Verified 13 Oct 2026.** This page is written by the team that makes Buckets. Buckets uses the same AWS APIs as the console. Your IAM policies, bucket policies, and AWS charges apply in exactly the same way.

The Amazon S3 console is free and needs no installation. When AWS launches an S3 feature, it appears there first. AWS also offers Storage Browser for S3, a component that organizations can embed in their own web apps to give end users a browsing interface.

Buckets is a paid desktop app. It gathers S3, CloudFront, and the surrounding AWS administration into one window, and adds workflows the console does not have.

## Stay with the console if…

- **You touch S3 occasionally.** A browser tab is enough, and it costs nothing.
- **You need a feature AWS launched this week.** The console gets it first.
- **You can't install software** on the machine you use, or your organization only allows browser access.
- **You want one tool for every AWS service**, not just storage and delivery.

## Add Buckets if…

- **You work in S3 every day across several accounts or clients.** Switching between saved profiles and IAM Identity Center sessions takes one click, and sessions refresh themselves.
- **You move real files.** Drag folders in and out. Large uploads resume after interruptions. You can copy between buckets in different accounts side by side.
- **You want to know what an action costs first.** Examples include restores from archive storage, Batch Operations, and CloudFront invalidations (the first 1,000 paths each month are free).
- **You need recovery that works on a whole prefix.** Time Travel rebuilds an earlier state from retained versions and delete markers, and shows you a plan before applying it. It works from the version history S3 kept: a plan covers up to 200,000 versions and delete markers, incomplete plans are refused, and permanently deleted versions cannot be brought back.
- **You publish sites.** Deploy a local folder to a private bucket behind CloudFront in one reviewed step, and later syncs invalidate exactly the files that changed.

## Privacy and access

Buckets talks to AWS directly from your computer with your own credentials. ServerlessCreed never receives your AWS keys or file contents. The desktop app has no analytics or crash-reporting SDK. The [Trust Center](/trust) lists every connection it makes.
